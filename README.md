# AI Prompt Generator

A static site for building, saving and sharing AI prompts.

## What it does

- Compose a prompt from structured fields instead of a blank text box
- Dark mode, responsive layout
- Deployed through OpenClaw

## Stack

- Plain HTML, CSS and JavaScript — no build step
- Tailwind CSS for styling
- Deployed via OpenClaw

## Local preview

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
